# 실험 현황과 개선 제안

[메인 README](../../README.md)

## 현재 구현 범위

저장소에는 YOLO/OpenCV 기반 영상 검출, ROI 기반 판정, 기자재·분실물 FSM, 소형 객체 실험, 결과 시각화와 사건 보고서 생성 스크립트가 있습니다. 주차별 보고서는 computer-vision/lab_asset_lost_finder/docs/reports/에서 확인할 수 있습니다.

기존 README에 기록된 수치와 사건 예시는 특정 데모 영상과 실험 설정에서 나온 사례입니다. 전체 환경에 대한 정확도 보증이나 독립 평가 결과로 해석하지 않도록 이 문서에서는 일반화하지 않습니다. 현장 CCTV 스트림 연동, 운영용 서버·DB·배포 설정도 현재 저장소에서 확인되지 않았습니다.

## 다음 마일스톤 제안 — v0.2.0

이 버전은 제안 단계이며 확정된 릴리스가 아닙니다.

- 카메라·영상 입력과 ROI, 임계값을 설정 파일 또는 CLI 옵션으로 분리
- 학습·검증 데이터 분할, 클래스별 정밀도/재현율, 오탐·미탐을 재현 가능한 평가 보고서로 기록
- 영상 처리와 사건 판정 로직의 단위 테스트 및 짧은 샘플 영상 통합 테스트 보강
- FastAPI 이벤트 서버와 로컬 파이프라인 간 이벤트 계약 및 재연결 처리 연결
- 저장되는 영상·사건 정보의 보관 기간, 접근 제어, 개인정보 보호 기준 문서화

## 이후 검토 항목

실시간 스트림 운영이 필요해지면 카메라 장애 복구, 이벤트 큐, 인증·권한, 로그·모니터링, 결과 저장 정책을 설계하고 현장 데이터로 성능을 평가합니다. 실제 설치 전에는 고지·촬영 범위·접근 권한과 보관 정책을 별도로 검토해야 합니다.
