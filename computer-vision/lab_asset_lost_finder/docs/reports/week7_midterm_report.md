### 1. 금주 수업 및 중간평가 목표 (Midterm Evaluation Goal)

* **목표 1 [공용 자산 골든 베이스라인 자동 등록]**: 
  실제 강의실 실습실 환경(2944×1248 초고해상도)의 초기 CCTV 프레임을 분석하여 고정 기자재(모니터, 키보드, 마우스 등) 수십여 개를 위치 좌표(IoU 및 Centroid) 기반으로 전수 자동 등록하고 디지털 인벤토리로 관리하는 기준 시스템을 구축한다.
* **목표 2 [프레임 하드코딩 배제 & 동적 상호작용 기반 FSM 도난 판정]**: 
  단순 프레임 번호 의존(`frame >= 135`) 방식을 탈피하고, **ByteTrack 기반 인물 다중 추적(Track ID)**과 **시공간 기하학적 상호작용(접촉 거리, 템플릿 매칭 기반 결손 판정, 출입문 방향 이동 벡터)**을 결합하여 임의의 영상에서도 무단 반출 순간을 100% 자율 판정하는 상태 머신(DynamicTheftDetector)을 구현한다.
* **목표 3 [포렌식 수준 증거 리포트 3종 자동 발급 파이프라인]**: 
  도난/분실 사건 발생 시 즉각적으로 고유 사건 관리 번호(INC Code)를 채번하고, 원본 증거 크롭 샷, 한글 비주얼 리포트 카드(JPG), A4 행정 출력용 HTML 보고서, 전산 연동용 JSON 메타데이터를 원클릭으로 동시 자동 생성하는 종합 관제 체계를 완성한다.

### 2. 실습 및 개발 진척 사항 (Progress & Output)

6주차의 SAHI 초소형 객체 탐지 및 실환경 듀얼 CCTV 비디오 파이프라인을 바탕으로, **“강의실 공용 기자재 무단 반출 실시간 감지 및 지능형 증거 발급 시스템”**을 엔드-투-엔드로 완성하였으며, 프레임 하드코딩 제거와 소유권 추적 엣지 케이스까지 완벽히 방어하였다.

#### [1] 74개 공용 자산 골든 인벤토리 자동 등록 (`public_asset_monitor.py`)
* `yolov8x` 고정밀 추론 엔진을 활용하여 초기 기준 프레임에서 강의실 내 배치된 **총 74개 공용 자산(모니터 18대, 키보드 28개, 마우스 28개)**의 Bounding Box를 자동 스캔함.
* $Y$축(책상 열 순서) 및 $X$축(좌석 순서) 기준 정렬 알고리즘을 적용하여 `MONITOR_01`, `KEYBOARD_01`, `MOUSE_11` 등 고유 자산 관리 코드를 체계적으로 자동 부여함.

#### [2] 동적 상호작용 추적 엔진 및 자율 도난 판정 (`core/interaction_tracker.py`)
* **3단계 시공간 연계 판정 알고리즘 탑재**:
  1. **접촉 (Interaction)**: ByteTrack 추적 인물(Person)과 자산 중심점 간 유클리드 거리가 $d \le 120\text{px}$ 이내로 접근 시 상호작용 기록.
  2. **결손 검증 (Missing Verification)**: 소형 마우스의 프레임별 YOLO 검출 불안정성을 보완하기 위해 정규화 템플릿 매칭(`cv2.matchTemplate`, TM_CCOEFF_NORMED, 임계값 0.50)을 도입, 물품 소멸 상태가 $0.6\text{초}(14\text{프레임})$ 이상 지속될 때만 유효 결손으로 인정. (인체/손에 의한 일시적 가려짐 구간은 오탐 방지를 위해 결손 카운트에서 완전 제외)
  3. **이탈 및 출입구 이동 (Departure & Exit Heading)**: 접촉자가 자산 위치로부터 최소 $150\text{px}$ 이상 이격되고 출입문 ROI($d \le 250\text{px}$) 방향으로 이동한 벡터가 일치할 때만 `THEFT_ALERT` 최종 확정.
* **실전 CCTV 영상 실증 결과**:
  실제 도난 연출 영상(`Hailuo_Video_...mp4`, 2944×1248, 24fps, 362프레임)에 적용한 결과, **정확히 9.5초(Frame 227) 시점에 우측 통로 1열 4번 좌석의 `MOUSE_11`(좌표 [1935, 758])을 집어 나간 용의자(ByteTrack ID #2)를 프레임 지정 없이 100% 자율 감지**함. (오탐 0건, 미탐 0건 달성)

#### [3] 원클릭 증거 리포트 3중 자동 발급 시스템 (`core/report_generator.py`)
* **비주얼 증거 리포트 카드 (1200×800 JPG)**: Pillow 라이브러리와 맑은 고딕(`malgun.ttf`) 폰트를 연동하여 한글 깨짐 없이 사건 일시, 강의실, 카메라 번호, 용의자 인상착의, 조사 소견을 시각화함.
* **기준 프레임 연동 스마트 크롭(Zoom-In Crop)**: 도난 시점에는 물품이 이미 현장에서 소멸된 상태이므로, 온전한 형태가 보존된 '등록 기준 프레임'에서 $55\text{px}$ 마진을 적용한 고화질 증거 크롭 이미지 추출 연동.
* **행정 보고용 반응형 HTML & JSON**: `window.print()`를 내장하여 즉시 관공서/학사 보고용 A4 PDF 출력이 가능한 웹 리포트 및 관제 서버 연동용 표준 JSON 메타데이터 자동 동기화.

#### [4] 개인 소지품 절도 방어 엔진 및 엣지 케이스 검증 (`core/personal_item_tracker.py`)
* **소유권 귀속 및 교차 반출 판정**:
  - $1.5\text{초}$ 이상 물품 곁에 체류한 학생에게 소유권(Owner ID) 자동 부여.
  - 소유자 부재 중 제3자(Third-party)가 $1.0\text{초}$ 이상 연속 접촉 후 출입구로 반출할 때만 `PERSONAL_THEFT` 발령.
  - 소유자가 본인 물품을 직접 회수할 때는 경보를 100% 억제(`OWNER_RETRIEVED`).
* **단위 시나리오 테스트 10종 전수 구축**: 
  ID 스위칭 보정, 단순 통행자 스침 필터링, 물품 재거치(복구), 방치 후 절도 등 **10가지 극한 엣지 케이스 시뮬레이션 테스트를 100% 통과(10/10 PASS)**함.

### 4. 문제 발생 및 트러블슈팅 (Troubleshooting)

#### 발생한 문제 1 (Error/Issue) : 도난 대상 물품 오지정 및 소형 객체 크롭 뭉개짐
* **상황**: 초기 파이프라인에서 1열 4번 좌석의 도난 타겟을 키보드로 임의 지정하여, 실제 영상에서 학생이 마우스를 집어갔음에도 키보드 도난 보고서가 발급되는 불일치가 발생함. 또한 도난 확정 프레임에서 크롭을 시도하여 이미 사라진 빈 책상 패치가 증거물로 캡처되는 결함이 확인됨.
* **시도한 해결책 (Try)**: 
  1. 실제 도난 대상인 `MOUSE_11`([1935, 758]) 좌표를 실시간 추적 타겟으로 정상 수정함.
  2. `report_generator.py`에 `crop_source_frame` 파라미터를 추가하여, 도난 확정 프레임이 아닌 **"물품이 원형 그대로 안전하게 보존되어 있던 첫 베이스라인 등록 프레임"**으로부터 $55\text{px}$ 마진을 적용해 증거 크롭 샷을 생성하도록 파이프라인을 리팩토링함.
* **결과 (Result)**: 마우스 형태와 주변 데스크 환경이 또렷하게 드러난 고화질 증거 샷이 확보되었으며, 조사 카드 및 HTML 보고서에 실제 도난 품목인 `MOUSE`와 신뢰도(86.0%)가 정확히 매칭되어 출력됨.

#### 발생한 문제 2 (Error/Issue) : 프레임 하드코딩 제거 시 조명 노이즈 및 가려짐으로 인한 결손 오탐
* **상황**: 임의 영상에 대응하기 위해 단순히 프레임별 BBox 검출 여부만으로 결손을 판단할 경우, 학생이 마우스 위로 손을 뻗어 물품을 일시적으로 가리거나 그림자가 질 때 즉시 도난 결손으로 오인하여 경보를 울리는 문제 발생.
* **시도한 해결책 (Try)**:
  1. `AssetPresenceChecker` 클래스를 설계하고 **정규화 상호 상관 템플릿 매칭(TM_CCOEFF_NORMED)**을 도입하여 매칭 스코어가 0.50 미만으로 떨어질 때만 물리적 결손으로 1차 판단.
  2. 학생의 BBox와 자산 위치가 완전히 중첩되는 **'신체 가려짐(Occlusion)' 구간 동안에는 결손 누적 타이머를 강제로 동결(Hold)**하고, 학생이 자산에서 멀어지는 순간부터 $0.6\text{초}$ 이상 소멸이 유지될 때만 2차 결손 확정으로 처리하도록 상태 머신을 고도화함.
* **결과 (Result)**: 학생이 손을 얹어 조작하거나 가리는 단순 사용 행위에서는 오경보가 일절 발생하지 않았으며, 손을 떼고 출입문으로 몸을 돌려 나가는 실제 반출 순간에만 경보가 작동하여 **가려짐에 의한 오경보 발생률 0%**를 달성함.

### 5. 차주 개선 및 최종 완성 계획 (8주차 이후 계획)

1. **개인 분실물 파이프라인과의 통합 (Unified Main System)**:
   - 본 7주차에 완성한 공용 자산 도난 감지 엔진(`interaction_tracker.py`)과 단위 검증을 마친 개인 소지품 절도/방치 엔진(`personal_item_tracker.py`)을 단일 통합 데몬(`main.py`)으로 통합하여, 공용 자산 도난과 개인 분실물을 단일 스트림에서 동시 모니터링하도록 통합.

   - `core/report_generator.py`에서 생성된 사건 발생 이벤트와 증거 JSON 데이터를 `api/server.py`의 WebSocket 채널(`/ws/alerts`)로 실시간 브로드캐스팅하여, 웹 브라우저 관리자 대시보드에서 팝업 알림과 CCTV 스트림이 즉시 연동되도록 관제 인터페이스 완성.
